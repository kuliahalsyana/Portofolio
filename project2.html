SMART HOME & APPLIANCE CONTROL SYSTEM

Integrated residential electrical automation system featuring dual control modalities: wireless RF physical remote and a responsive JavaScript Web Dashboard.

🏠

SMART HOME DUAL-CONTROL SYSTEM

RF Remote Control • JavaScript Web Application • Multi-Zone Lighting & Appliances

🌐 INTERACTIVE JAVASCRIPT WEB DASHBOARD

Engineered a responsive Web Dashboard interface built with HTML5, CSS3, and modern JavaScript / Fetch API to toggle and monitor the real-time operational status of lighting and appliances directly from mobile or desktop browsers.

📡 WIRELESS RF PHYSICAL REMOTE CONTROL

Equipped with wireless RF remote controls for rapid on-site access without requiring smartphones or active internet connections, providing practical, latency-free operation for all household members.

⚡ OPTOCOUPLER RELAY MODULES & GRID ISOLATION

Designed with multi-channel optocoupler-isolated relay modules that galvanically decouple low-voltage DC logic circuits from high-voltage 220V AC mains, safeguarding the system from current surges and short circuits.
